Confidentialité

Fog Mirror fonctionne entièrement dans votre navigateur.

  • L’image de votre caméra ne quitte jamais votre appareil.
  • Rien n’est enregistré, sauf si vous enregistrez vous-même une image.
  • Pas de compte, pas de cookie, pas de mesure d’audience, pas de publicité.

La caméra

Fog Mirror demande l’accès à votre caméra pour afficher votre reflet et repérer votre bouche et votre main. Ce traitement est fait par votre navigateur, sur votre appareil, avec MediaPipe, une bibliothèque de Google. Aucune image ni aucune donnée tirée de l’image (position du visage, de la main…) n’est envoyée sur internet.

Le micro n’est pas utilisé. Vous pouvez retirer l’accès à la caméra à tout moment dans les réglages du site de votre navigateur ; fermer la page l’arrête aussi.

Les images enregistrées

Le bouton « Enregistrer une image » crée un fichier PNG directement sur votre appareil, dans votre dossier de téléchargements. Il n’est envoyé nulle part.

Ce qui est mémorisé dans votre navigateur

Pour ne pas vous les redemander, Fog Mirror garde dans le stockage local de votre navigateur :

  • le fait que vous avez terminé ou passé le guide d’accueil ;
  • vos réglages (épaisseur du trait, intensité de la buée, etc.).

Ces informations restent sur votre appareil. Vous pouvez les effacer en supprimant les données du site dans les réglages de votre navigateur.

Hébergement

Le site est hébergé sur GitHub Pages. Tous les fichiers nécessaires (code, modèles de détection) sont servis depuis ce même site : aucun autre service n’est contacté. Comme tout hébergeur, GitHub reçoit les informations techniques de chaque visite (adresse IP, navigateur) ; voir la déclaration de confidentialité de GitHub.

Code source

Le code de Fog Mirror est public : vous pouvez vérifier tout ce qui précède sur github.com/rrcedric/fog-mirror. Pour toute question, ouvrez un ticket sur ce dépôt.
